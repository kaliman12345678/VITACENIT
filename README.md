## 🌿 Estructura del Proyecto

* **`index.html`**: Portal principal con arquitectura completa de información, presentación de la ESAL, pilares fundamentales, programas sociales, galería de identidad, preguntas frecuentes interactivas y formulario de contacto.
* **`politica-de-privacidad.html`**: Política integral de tratamiento y protección de datos personales bajo la Ley 1581 de 2012 (Habeas Data) y normatividad colombiana.
* **`terminos-y-condiciones.html`**: Términos y condiciones legales de uso del portal web y servicios comunitarios de la entidad.

* **`robots.txt`**: Directivas de indexación limpia para motores de búsqueda.
